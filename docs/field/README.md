# Field entries

One file per real session of imece (record 111): a team or a solo on a
real task, on any repository. The screen's features come from here, not
from other programs. An entry is short and written the same day:

```
# YYYY-MM-DD <repository> · <what was asked>

- Setup: workers, tiers, confine, pot; how long, what it cost.
- What rubbed, one line each, with the seam it came from in brackets:
  [leader] [bus/board] [Δ] [sessions] [screen] [install]. A seam that
  did not rub is left out.
- What was done about each: an issue number, a record, or "left".
```

Name the file `YYYY-MM-DD-<repository>.md`. A session that rubbed
nothing still gets an entry: that is a finding too. Nothing of what an
agent wrote goes in here verbatim; say what happened.
